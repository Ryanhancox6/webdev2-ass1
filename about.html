    About the website

    Ryan's Watchlist was built for Assignment One of Website Development 2 using HTML, CSS (with Flexbox) and JavaScript. It has three pages: a welcome page, the My Watchlist page where the data can be viewed, added to, deleted and searched, and this about page.

    The data is an array of objects in js/data.js. It holds 15 films and TV series I've watched or want to watch, from classics like Back to the Future and Jurassic Park to series like Breaking Bad and The Office. Each object has a title, type (film or series), whether I've watched it (true or false), my rating out of 5 and a short review.
